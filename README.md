# Afforestation Impact Modelling

A simple project that estimates the carbon dioxide (CO₂) absorbed by trees over a period of time.

## Features

- Calculates estimated CO₂ absorption
- Uses number of trees, years, and survival rate
- Displays results using a simple Streamlit app
- Helps understand the environmental impact of tree plantation

## Technologies Used

- Python
- Streamlit
- Pandas
- Altair

## Files

- `app.py` – Main Streamlit application
- `requirements.txt` – Required Python libraries
- `Welcome_to_Colab.ipynb` – Notebook used for project work
- `.gitignore` – Files ignored by Git
